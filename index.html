Welcome to the Reboot LAN Admin Panel

This interface requires backend authentication for access. Ensure you are authorized before proceeding.

Security Fixes and Recommendations

  • Backend authentication requirement for admin panel
  • CSRF token protection implemented
  • Server-side session validation enforced
  • Encrypted local storage for JWT tokens
  • Admin panel is hidden by default and only visible after successful authentication
  • PIN verification moved to backend for enhanced security
  • Rate limiting hints provided
  • Kiosk PIN hashed validation is enforced
  • HTTPS enforcement is recommended
  • Secure cookie flags documentation included
